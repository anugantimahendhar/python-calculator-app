
# Python Calculator App

A simple desktop calculator application built using 
Python and Tkinter with a modern dark-themed interface.

## Features

- Addition, subtraction, multiplication and division
- Percentage calculation
- Decimal number support
- Clear and delete functionality
- Division-by-zero error handling
- User-friendly graphical interface

## Technologies Used

- Python
- Tkinter
- Visual Studio Code
- Git and GitHub

## Project Structure

    Python-Calculator/
    ├── calculator.py

    ├── README.md

        └── calculator.png

## How to Run

1. Install Python 3.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run the following command:

       python gui.py

## Limitations

- Supports two-number calculations at a time.
- No keyboard shortcuts or scientific calculations.
- Percentage converts a number into its decimal value.
